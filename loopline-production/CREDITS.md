# Credits

## Base project

Loopline is built on top of an MIT-licensed Next.js starter kit. The original
license is preserved in [LICENSE](./LICENSE).

**Original project**: AI SaaS Starter Kit (Next.js)
**License**: MIT
**Modifications**: Complete rebrand (Loopline design system), new feature set
(AI customer-support chatbot, embeddable widget, multi-bot workspaces, human
handoff inbox, Stripe billing), new database schema, new marketing copy.

## Artwork

All illustrations (hero, empty states, setup guides) are **original artwork**
created for the Loopline template project. They are inspired by the flat
illustration style popularized by unDraw but are not derived from any specific
unDraw illustration. No third-party illustration licenses are required to
resell this template.

The Loopline logo and brand marks are original designs owned by this template
project.
